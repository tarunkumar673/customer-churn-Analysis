# Customer Churn Analysis

## Project Overview

This project analyzes customer data to identify churn patterns and high-risk customer segments using Python, SQL, and Tableau.

The analysis covers customer demographics, services, tenure, payment methods, monthly charges, and contract types to understand factors associated with customer churn.

## Objectives

- Analyze overall customer churn
- Identify churn patterns and high-risk customer segments
- Analyze churn by contract type
- Analyze churn by internet service
- Analyze churn by payment method
- Analyze customer tenure and monthly charges
- Perform SQL-based customer analysis
- Build an interactive Tableau dashboard

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL / SQLite
- Tableau

## Dataset

The dataset contains 7,043 customer records and 14 attributes related to customer demographics, services, tenure, charges, and churn.

## Data Analysis

Python and Pandas were used for:

- Data cleaning
- Missing value handling
- Duplicate checking
- Exploratory Data Analysis (EDA)
- Customer segmentation
- Churn rate analysis
- Correlation analysis
- Data visualization

## SQL Analysis

SQLite was used to perform customer segmentation and churn-related SQL queries, including:

- Total customer count
- Churn analysis
- Contract-wise churn
- Payment method analysis
- Tenure-based customer analysis

## Tableau Dashboard

An interactive Tableau dashboard was created to visualize:

- Churn Distribution
- Churn by Contract Type
- Churn by Internet Service
- Churn by Payment Method
- Churn by Tenure
- Churn by Monthly Charges

## Key Insights

The analysis highlights differences in churn patterns across:

- Contract types
- Customer tenure
- Internet services
- Payment methods
- Monthly charges
- Customer demographics

These findings can help identify customer segments that may require targeted retention strategies.
